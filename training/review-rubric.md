# Review rubric

Classify findings as Blocker, Major concern, Improvement, or Nit/question. For every Blocker or Major concern, state:

1. what can go wrong;
2. the conditions required;
3. why the severity is justified;
4. the smallest safe fix;
5. the test that proves both the defect and fix.

Review intent, correctness, boundaries, failure behavior, async/cancellation, nullability, transaction safety, tenant ownership, API truthfulness, query shape, resource lifecycle, observability, and test evidence.
